# Fitting Bayesian Models of Perception on Behavioral Data

This Python repository provides reusable demo code for fitting Bayesian models on trial-by-trial estimation data, as developed by

* Hahn, Wei, [A unifying theory explains seemingly contradicting biases in perceptual estimation](https://www.nature.com/articles/s41593-024-01574-x), Nat Neuro 2024 (code: https://gitlab.com/m-hahn/unifying-theory-biases)
* Hahn, Wang, Wei, [Identifiability of Bayesian models of perception](https://www.pnas.org/doi/10.1073/pnas.2601013123), PNAS 2026 (code: https://github.com/m-hahn/identifiability-bayesian-models)

The scripts here are extracted from those repositories and put into a standalone format, making application to new data more convenient.

The workflow is documented in [`code/Demo/README.md`](code/Demo/).

To upload a CSV with behavioral data and run a fit interactively, use [`code/Demo/Fit_Your_Own_Data.ipynb`](code/Demo/Fit_Your_Own_Data.ipynb) or [open it in Google Colab](https://colab.research.google.com/github/m-hahn/bayesian-models-of-perception/blob/main/code/Demo/Fit_Your_Own_Data.ipynb).

To fit models on your own data, interactive running via .ipynb might be a good starting point.
